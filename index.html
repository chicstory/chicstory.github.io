1. 꿀키워드 발굴 & 상세 분석

어떻게 쓰나요? 키워드를 검색한 뒤 표에서 원하는 키워드 행을 클릭하면 아래에 1년 검색 추이 · PC/모바일 & 타깃 추이 · 공략 난이도 · 수익성 4가지 상세 카드가 열립니다.
네이버 실시간 자동완성 (클릭 시 재검색)
키워드를 입력하면 월간 검색량, 문서수, 경쟁강도를 계산합니다. 키워드를 클릭하면 상세 분석 카드가 열립니다.

2. 상위노출 순위 조회

어떻게 쓰나요? 노리고 있는 키워드와 내 블로그 ID(또는 blog.naver.com/아이디 주소 전체)를 넣으면, 현재 네이버 블로그 검색(정확도순) 1~30위에 어떤 글들이 있는지와 내 블로그가 몇 위에 있는지 바로 확인합니다.
특정 키워드에서 현재 네이버 블로그 검색 상위 1~30위와 내 블로그 순위를 확인합니다.

3. 내 글 누락 일괄 진단

어떻게 쓰나요? 내 블로그 주소(https://blog.naver.com/아이디)를 통째로 붙여넣거나 ID만 입력하면 최근 글 15개를 자동으로 불러와 네이버 검색 누락 여부를 진단합니다. 제목에 특수문자([], (), ·)가 많으면 일시적으로 누락 의심으로 뜰 수 있으니 링크를 눌러 직접 확인해 보세요.
블로그 ID를 입력하면 RSS에서 최근 글 15개를 불러와 네이버 검색 누락 여부를 일괄 진단합니다.
